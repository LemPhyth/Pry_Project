# UI 需求实施与接口交接

日期：2026-09-14。负责人：Codex 前端。依据：`ui-frontend-handoff.md`、`ui-design-system.md` 和当前 API 契约。

## 结果与范围

实现 UI-021、UI-022、COMP-004、COMP-006 中已有契约支持的主体功能；不是全部设计验收完成，也不是发行版本。本轮未修改后端、数据库或接口，未提交协作者的工作区改动。

### 已实现

- 壁纸连续覆盖角色栏、消息与输入工作区，不随历史抽屉开关重新裁切；提供透明度、压暗和模糊设置。消息、元信息、空状态和连接提示使用局部阅读表面；图片失败回退，忽略过期下载结果。
- 头像互动和切换角色为独立入口。单击读取动作配置，双击只执行一次戳一戳；Enter/Space、Esc 和焦点返回有明确处理。失败重试沿用幂等键，不在前端伪造助手消息。
- 角色编辑页增加独立保存的互动配置：预设回复、权重、启用状态、排序、动作和冷却。保存失败保留草稿。
- 宽窗历史侧栏、窄窗历史抽屉；Tab 在抽屉内循环，Esc 返回入口，支持 860×620 最小窗口。
- 动态模型列表、本地扫描、名称/标签搜索、来源/能力筛选、标签编辑、网络模型增改删。不可用模型保留说明并禁止选择；标签不作为能力依据。
- 高级参数内联展开、按模型保留未保存草稿；扫描不主动替换用途选择。首次选择采用后端选中投影，不随意选第一项。未改参数时不提交覆盖映射。
- Embedding 独立选择、启停、保存、状态轮询和补建索引；降级不禁用聊天。前端不生成向量、不启动模型进程。
- 头像面板可进入主动话题设置，读写后端策略、安静时段、频率和状态。活动报告不包含按键或草稿正文；退出有有界注销等待。
- 会话未读与托盘计数来自持久化投影。窗口前台、消息在底部可见且非管理页面时才提交所见消息 ID，不因预取或 SSE 到达直接清零。
- 阅读旧消息时保留滚动位置并显示新消息入口；断线恢复补取历史和未读。切会话、消息加载及列表刷新有过期结果保护，发送完成不清空其他会话的草稿。

## 仍未完成的具体边界

1. **壁纸构图恢复**：`UpdateAppearanceMediaRequest.BackgroundDisplay` 可写，但 `ClientPreferencesResponse` 只有 `BackgroundUrl`，没有焦点/缩放参数。当前居中覆盖，不覆盖已有构图设置；不能声称恢复原构图。后端需补读取投影，前端再接入裁切能力。UI-021 此项未完成。
2. **原始模型参数覆盖**：模型响应仅返回生效值，偏好响应不返回原始 `ModelTunings`，而更新字典替换整个映射。当前未改参数发送 null；编辑参数时只能提交列表模型的生效值快照，无法保留“未设置、继承默认”的原始区别。建议后端返回原始覆盖映射或提供明确的按模型局部更新契约。UI-022 无损往返仍有此限制。
3. **网络地址回显**：列表响应无 `BaseUrl`。编辑留空采用后端已有的保留原地址语义，能保存其他字段，但不能显示原地址。新建仍要求有效地址。
4. **通知预览偏好/系统通知**：已实现列表和托盘未读，未实现系统弹窗和持久化通知预览开关。主动策略安静时段不冒充通知偏好；需冻结通知偏好契约。COMP-006 未全部完成。
5. **角色主题与桌宠**：COMP-007 缺少体验映射及资源契约，本轮不猜测字段、不串用资源。
