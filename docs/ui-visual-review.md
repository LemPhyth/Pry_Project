# UI-023 视觉统一与验收记录

日期：2026-09-14。负责人：Codex，UI 设计与页面绘制。

作者要求恢复设计方原先设想的主窗口，并检查其他界面的视觉一致性。本轮直接调整页面表现，保留前端已经接入的模型库、Embedding、头像互动、主动话题和已读能力；未修改后端、契约或数据库。

## 设计调整

| 页面 | 发现的问题 | 本轮调整 |
|---|---|---|
| 陪伴 | 壁纸模式的助手消息横向拉满，提前返回导致头像消失；角色栏与消息同样厚重 | 始终显示角色头像，短消息按内容收窄；有壁纸时正文与元信息共用局部阅读底面，无壁纸时保持连续正文；长消息仍自动换行 |
| 角色入口 | 顶部横跨全窗的实色栏过重 | 中央紧凑角色入口，头像互动与切换独立；历史和新对话位于两侧，保留窄窗抽屉 |
| 输入 | 连接与回合提示各自贴底色，像散落的标签；用户消息存在双重底面 | 状态整合进输入容器，消除单独标签和用户消息的重复底面，保留停止回复、附件、录音和发送行为 |
| 设置 / 模型库 | 新增分组缺少统一层级，标签与模型条目反复套卡片 | 聊天、记忆检索与模型库使用一致分组；模型条目改为分隔列表，统一标题、辅助文字、筛选及编辑字段间距 |
| 角色 / 互动配置 | 字段字号与间距分散，回复预设与动作操作挤在一起 | 统一标题与标签尺寸；互动区独立分组，动作与预设采用规律留白和分隔；独立保存语义不变 |
| 记忆 / 表情 | 小字号偏多，长表单无法完整滚动，按钮只设背景色；表情页保留旧固定蓝黑底 | 共享字体与颜色，详情滚动、底部操作固定；主按钮复用完整状态，移除硬编码旧色 |
| 主动话题 | 所有字段平铺，保存按钮随长表单滚走 | 分为联系节奏与安静时段，起止时间并列；保存与状态留在固定底部 |
| 弹窗 / 菜单 | 确认弹窗仍为旧深蓝风格，小面板圆角不一致 | 使用当前浅深主题与共享按钮，长说明独立滚动；菜单与附属面板统一圆角 |

颜色仍尊重用户保存的强调色。本轮不将用户主题改写成设计预览色，也不把未定稿角色服装变成正式应用资产。连续壁纸、后端构图读取缺口和角色主题包依赖沿用前端原有边界。

## 实现规则

- `Services/PryUi.cs` 提供程序化页面的 Heading、Hint、Field、Section、Footer、Actions 表现基元；新增功能界面优先复用。
- `App.axaml` 管理按钮、危险操作、输入控件、菜单与展开控件的公共样式。主按钮使用 `primary` 类，危险操作使用 `danger` 类，不只写死背景颜色。
- 分组标题 18、辅助文字与字段标签 13，正文保持可读的行高；主要间距 8 / 12 / 16 / 24。
- 输入和按钮圆角 8，分组与阅读面 12，主输入容器及角色入口 16。头像按用途保持圆形或一致预览圆角。
- 列表内容与编辑表单各自承担信息层级；不要将每个子字段再次包成卡片。模型库和互动配置的独立保存语义通过分组说明表达。
- 本轮修改属于最新视觉实现，覆盖 [ui-frontend-handoff.md](ui-frontend-handoff.md) 中未约束清楚的“阅读底面”细节。功能契约与已有未完成边界仍参考 [ui-implementation-report.md](ui-implementation-report.md)。

## 验证

- Release 构建：0 警告、0 错误。
- 全套测试：Core 33 通过 / 1 个真实语音权重测试按条件跳过，API 44、Client 7、App 162，共 246 通过、1 跳过。
- 本机隔离后端使用 `.local-notes/ui-023/data`，空模型扫描目录；未使用日常会话数据库或加载真实模型。
- 真实窗口检查：浅色复杂壁纸、头像单击动作面板、Esc 关闭、双击戳一戳、设置导航、模型库滚动与网络模型编辑区。双击后通过隔离 API 确认只有一条 `Assistant / interaction_preset` 消息，没有同时打开单击面板。
- 应用渲染：浅深主题、1180×800 与 860×620、复杂壁纸与无壁纸、长角色名、中英文长消息、历史抽屉、角色、记忆、表情、主动话题、设置、模型库、网络编辑与确认弹窗。短消息阅读面实际测量 242 DIP，不再拉满 760 DIP 阅读列；工作区切换后草稿保留。
- 预览输出：本机忽略目录 `.local-notes/ui-023/final-renders`。使用测试文案与 Sample 参考作内部验证；不是正式素材，也不将应用渲染冒充原生截图。原生屏幕检查包含模糊效果，离屏渲染不作为该效果的唯一证据。
- 差异空白与仓库检查通过；未跟踪的本轮表现基元及文档另检。未提交、暂存或发布。

## 保留的验证边界

本轮没有改变 Windows 全局缩放，150%/200% 系统 DPI 尚未实测；最小窗口渲染不等于系统 DPI 验收。未加载真实 Embedding 或主动话题模型，没有重新执行完整模型联调。已有壁纸构图投影、参数覆盖往返和系统通知等接口缺口不由视觉代码绕过，UI-021/022/COMP-006 原任务状态不因本次视觉统一而变成全部完成。
