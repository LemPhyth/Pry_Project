## 全局约束（四把刀共用，逐条可判红）

1. 独立 worktree 或独立分支；开工前 `git status --short --branch`，他人未提交成果（含当前两份已暂存文件与四份未跟踪材料）视为对方所有，不覆盖、不代提交、不 `reset/checkout/clean`。
2. `MainWindow.axaml.cs` 及同族宿主文件、SQLite 迁移登记表、共享计划同一段，同一时间只允许一名写者。
3. 本波不接线生产路径、不切换引擎、不删除旧链，因此**不产生新的发行候选**；`git tag`、`git push`、实际打包仍需作者明令。
4. 不改美术协议，不改代码许可声明（AGPL-3.0-only 与三家照搬白名单已是现行事实）。
5. 在册门禁 988／0／2 是 `e82499b` 载体的历史读数，改写权只在 QA：各刀自跑数只写进自己工单，不顶账、不封基线。新判据条数必须先逐文件 `grep -c '[Fact]'`，再把总数与四项分项顶账。
6. 引用总数必须写全分项；受损或作废读数换目录换名重跑，不拿反证也不引用。`dotnet test` 只认长参 `--results-directory`，可信证据是 TRX 存在且 `<Counters>` 非零；`measure-fixed-eval.ps1` 会写 `fixed-eval-coverage.json`，跑法必须带 `-ResultsDirectory`，且它的覆盖 JSON 不是新链验收。
7. 真实用户数据目录 `%LOCALAPPDATA%/PryCompanion` 在 HDS-001 取得备份恢复证据之前**只读**；任何迁移实验只在合成数据或授权的隔离副本上做。
8. 他机资源：那台 PC 可用提交被 ComfyUI 吃掉约 10 GB，门禁出现 SQLite `disk I/O`／`out of memory` 判为资源形状，读数作废、绝不动他的进程。

## HDS-001｜冻结资产与可恢复地基

Owner：Platform / Persistence。前置：无。落点：新增恢复地基与迁移治理，不碰 schema 版本内容。

要交付什么：
- 在线一致性备份（含 SQLite WAL 与 `-shm`/`-wal`，不是只复制主 db）、逐文件散列校验、`PRAGMA integrity_check`、恢复到**另一个隔离目录**并核对行数/稳定 ID/引用/索引/外键/墓碑/孤立态/偏好。
- 备份集合覆盖角色卡、设置、数据库与受管媒体依赖；**不含** token、密钥、`runtime.json`、日志。
- 初始化前识别未知高版本结构并拒绝写入；迁移有登记、事务边界、失败回退与幂等要求。
- AUD-05 的落点：这条欠账先于任何用户数据迁移。

出口证据：合成数据与授权隔离副本上的可复现备份—破坏—恢复记录；未知高版拒绝写入的行为测试；一份真实数据**未被写入**的核对。

不许走的捷径：不许把"回滚旧二进制"当数据可恢复的证明；不许在本刀顺手预占 schema 11 或改表；不许只验备份存在而不验恢复；不许把真实用户目录当测试载体。

结果（2026-10-21）：本刀由守门人代派至隔离 worktree 实现（`3b65ccc`，基线 `a839e5f`），合流树门禁全绿后归位为主线 `8ef7d01`，状态＝**已实现待验**。四条捷径逐条核过：数据库走 `VACUUM INTO` 在线快照且硬排除 `.db`/`-wal`/`-shm` 的原始拷贝（不是"回滚二进制"）、迁移登记清单里 `TargetVersion > SchemaVersion` 会被 `ValidateRegistry` 直接拒（schema 11 未预占，产品代码里也没改表）、备份与恢复各自独立成用例且恢复到隔离目录逐格核对、真实数据目录 `%LOCALAPPDATA%/PryCompanion` 本轮零写入（40 个文件、树内最新写入仍是 10-19 13:27 他自己那次运行）。读数＝总 1052／0 红／2 条环境跳过（客户端 106／界面 233／后端 251／核心 462 执行 460），随刀新判据 37 例；**在册基线照旧是 QA 复采的 988／0／2，改写权在 QA**。**没做到的一件事**：备份／恢复仍未接生产路径（无端点、无 UI 入口、触发时机属产品决策），所以作者那侧今天还点不到"备份"这个按钮。明细见总计划 §9 同日 entry。

## HDS-002｜稳定身份与存储契约（本波只做契约设计＋纯领域类型）

Owner：Architecture + Persistence（写入者唯一，先登记）。前置：HDS-001 的数据保护；契约设计可与 001 并行。

要交付什么：
- `CharacterInstanceId` = LocalUser × Character 的稳定映射与迁移/alias 方案：不得每次启动重建，不得只给 CharacterId 换名，不得批量换随机 ID 丢原证据。
- `NarrativeRequest/Draft/Commit`、`CommunicationAction`、`DeliverySegment`（唯一键 `(commitId, actionId, segmentIndex)`）、`NarrativeIntent`、`KnowledgeCandidate` 的契约语义与归属；`ProcessedThroughSeq` 与 `PerceivedInputRefs` 分开。
- 单一 outbox 的归属方案：不得同时存在旧 reply plan 与新 outbox 两份可发送真相。
- 数据目录进程级独占写入锁的形状：`runtime.json` 只负责发现，不是所有权锁；第二个宿主不得告警后继续写；所有权丢失后条件提交必须拒绝。
- 新代码落在 `Pry.Core.Narrative` 等纯领域命名空间，不依赖 HTTP、Avalonia、SQLite 或进程类型。

出口证据：契约文档＋可编译纯领域类型＋三类反例行为测试（同实例双写者被拒、段唯一键冲突、迟到提交在条件写处被拒）。

不许走的捷径：不许在本波做生产迁移或引擎切换；不许把上游类型当 Pry 契约；不许用命名空间挪动冒充解耦（既有 Core 里的 HTTP/SQLite 实现另刀搬）；不许引入外部 actor 框架或 Agent 平台作前置。

结果（2026-10-21）：本刀由守门人代派至隔离 worktree 实现（`5145bde`，起点 `1c2e83d`、rebase 到 `86cd08c`），归位方式＝fast-forward（它是线尾的严格后代，没有撞位）；契约文档那批未提交的更正由守门人代归位成 `e9a8055`。状态＝**已实现待验**。四条捷径逐条核过：0 处删改现存文件、不落表不预占版本（本波 −0 行）、8 个新文件连一行 `using` 都没有（无 HTTP／Avalonia／SQLite／进程类型）、未引入任何外部 actor／Agent 框架。三类反例出口证据齐（双写者被拒／段唯一键／迟到提交在条件写处被拒，提交信息写了拆掉的具体守卫与行号，守门人核过那五行号确为那五条断言）。**但要紧的一条：它自报的那轮门禁不作数**——逐份 TRX 显示它跑的是 rebase 前的旧二进制（HDS-001 的四个 Core 测试类 32 例与 Client 5 例在它整轮读数里根本没出现，Core 491＝462−32+61）；合流树由守门人另起一轮全新构建＋全量测试＝**总 1113／0 红／2 条环境跳过**（客户端 106／界面 233／后端 251／核心 523 执行 521），随刀新判据 61 例，构建 **1 个警告**（它自己测试文件里 xUnit2012 一处，为一行改它不再起第二轮构建，登记等下一把顺手带走）。在册基线照旧是 QA 复采的 **988／0／2**，这三把都等同一次复采。该 lane 最终在 150 轮上限被系统停掉。明细见总计划 §9 同日 entry。

## HDS-003｜新生成中心隔离原型

Owner：Runtime / Intelligence。前置：本文件；与 001/002 可隔离并行。落点：隔离原型，**不接生产库、不发真实消息**。

要交付什么：
- 唯一装配入口的七段 Context Compiler（§6 分区与预算不等式），并修掉 AUD-01/AUD-06 的形状：默认 1.7B 不降档也能得到正的输入预算，Advisory 式旁路不再存在。
- 一次主叙事提案共同产出处境＋通信决定；即时正文必须能在原文中唯一定位，宿主计算位置与散列，不要求小模型算 UTF-16 偏移；绑定缺失或歧义即拒绝该动作，不许编"合理回复"。
- 沉默（合法无外发提交）、延后（只落意图，不进真实历史）两条路径各一条可复现样例。
- 真实模型对照：本地默认候选与一个明确版本 API 档，同固定 Canon/输入/参数，记录全部样本与失败、p50/p95、token、显存、调用次数；形状三选一对比（旧路线／只加剧情提示的对照／新主链）。

出口证据：v4 §14.1 架构身份验收——摘掉或替换 `BehaviorPlanner`、`ReplyGenerationRenderer` 与 MaiCore 必要性评分后新链路仍产出，且没有回落旧链；删掉叙事来源或把正文换成另一提案时，绑定与连续性测试必须报警。

不许走的捷径：不许在旧 `IReplyAdvisor` 里塞一段剧情再交给 `ReplyPlanner` 冒充新架构；不许双写真实用户状态；不许挑最好样本、拿截图当预期答案；不许预先伪造"提升百分比"；模型实验要占他那台机器或他密钥的 API 额度，**动手前先要作者点头**；小模型结构不稳时先减可选字段/窗口/叙事长度，不许偷偷改回旧链或放松来源与投递安全充当完成。
