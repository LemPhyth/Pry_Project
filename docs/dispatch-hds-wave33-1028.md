## 六 不许走的捷径（逐条对照前几把踩过的坑）

1. 不许为了"能跑"把任何阈值／窗口／有效期写成源码常量——那等于新增数字门槛，正面违反 §一.4。
2. 不许新增第三套身份/来源枚举（§〇.6⑤）；绕不开就登记论证，不许静默加。
3. 不许用"两条路径都调同一个构造所以恒等"当覆盖证据；要钉绝对字面量＋区分性探针。
4. 不许把"红不了"当成结论而不试：方向类突变（`>`↔`>=`、`ThenBy`↔`ThenByDescending`、删掉一行赋值、摘掉一个合取支）先穷举一遍再登记。

6. 不许把别人的未提交改动、暂存项、未跟踪资产读进自己的改动集或提交；共享脏树里禁裸 `git commit`。

8. 不许在报告里替守门人写状态词、结案词，也不许自封在册基线。
